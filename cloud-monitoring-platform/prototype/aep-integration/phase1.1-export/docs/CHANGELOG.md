## [1.1.1] - 2026-02-08

### 🐛 Bug修复
- **BLD-001**: 修复构建脚本架构缺失问题 - 创建缺失的 `scripts/build/build.sh`
- **BLD-002**: 标准化Maven构建流程实现
- **ENV-001**: 修复环境变量配置文件缺失问题 - 创建 `.env` 和 `.env.test` 文件
- **ENV-002**: 修复ConfigService配置优先级错误 - 环境变量优先于系统属性
- **ENV-003**: 修复构建脚本环境变量集成缺失 - 自动加载和验证环境变量

### 🔧 改进
- **IMP-003**: 构建脚本参数标准化 (`--clean`, `--skip-tests`, `--verbose`, `--quiet`, `--package-only`, `--profile`)
- **IMP-004**: 构建时间跟踪和产物报告增强
- **IMP-005**: 与现有测试框架(run_tests_enhanced.sh)集成
- **IMP-006**: 环境变量安全管理 - 密钥遮挡显示和文件权限控制
- **IMP-007**: 测试模式支持 - 添加 `--test-mode/-t` 参数使用 `.env.test`
- **IMP-008**: 配置验证增强 - 检查必需环境变量完整性

### 📚 文档
- **BUILD_ERRORS.md** - 创建构建错误追踪文档(类似WIN_ERRORS.md)
- **构建脚本帮助** - 完整的命令行参数说明和使用示例

### 🛠️ 技术实现
- 遵循项目现有脚本模式(颜色日志、错误处理)
- 支持AEP测试模式集成 (`AEP_TEST_MODE=real/mock`)
- 自动检测`.mvn/jvm.config`配置加载
- 健壮的Maven vs javac构建检测

### ⚡ 性能
- 构建时间报告: 清理构建 ≈ 15-20秒 (OpenJDK 21, macOS)
- 增量构建: ≈ 8-12秒
- 生成产物: `aep-data-exporter-1.0.0.jar` (约1.5MB)

## [1.0.0] - 2026-01-05

### 🎉 首次发布
- **产品数据导出** - 支持AEP平台产品信息导出
- **设备数据导出** - 支持设备详细信息导出
- **多格式支持** - JSON和CSV格式输出
- **命令行工具** - 完整的命令行参数支持
- **环境变量配置** - 安全的认证信息管理
- **错误处理** - 完整的错误处理和日志记录

### 🛠️ 技术栈
- **Java**: OpenJDK 21 LTS (推荐)
- **构建工具**: Maven 3.9.11 + 传统javac支持
- **依赖**: AEP官方SDK + Apache HTTP Client
- **操作系统**: macOS, Linux, Windows

### 📋 基础功能
- `--export-all` - 导出所有产品和设备数据
- `--export-products` - 仅导出产品数据
- `--export-devices` - 导出指定产品的设备数据
- `--format json|csv` - 指定输出格式
- `--output-dir` - 自定义输出目录

## 版本说明

### 🏷️ 版本编号规则
- **主版本号**: 重大架构变更或不兼容更新
- **次版本号**: 新功能添加或重要改进
- **修订版本号**: Bug修复和小幅改进

### 📅 发布周期
- **主版本**: 根据重大功能需求
- **次版本**: 每月或根据功能完成度
- **修订版本**: 根据Bug修复需求

### 🎯 版本状态
- **[Unreleased]**: 开发中的功能
- **[x.y.z]**: 已发布的稳定版本
- **已知问题**: 记录在KNOWN_ISSUES.md中
