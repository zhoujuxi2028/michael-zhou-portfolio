## 技术实现建议

### SQL去重语句
```sql
-- 1. 清理空白和空值记录
DELETE FROM device_table
WHERE imei IS NULL OR imei = '' OR imei = '\N' OR TRIM(imei) = '';

-- 2. 创建临时表保存唯一记录
CREATE TEMPORARY TABLE temp_unique_imei AS
SELECT imei, MAX(id) as max_id
FROM device_table
WHERE imei IS NOT NULL AND imei != '' AND imei != '\N'
GROUP BY imei;

-- 3. 删除重复记录
DELETE FROM device_table
WHERE id NOT IN (SELECT max_id FROM temp_unique_imei);
```

### 约束添加
```sql
-- 添加唯一性约束
ALTER TABLE device_table
ADD CONSTRAINT uk_imei UNIQUE (imei);
```
