## [1.1.0] - 2026-01-25

### 🎉 新增功能
- **默认模式支持** - `./query.sh` 无参数时自动使用 `--export-all --format csv --quiet`
- **输出文件路径显示** - 安静模式下显示具体的输出文件位置
- **进度指示器** - 添加"准备数据导出，请稍候..."提示
- **安静模式优化** - 简化输出，只显示关键信息

### 🔧 改进
- **IMP-001**: 添加输出文件路径显示（./output/products.csv, ./output/devices.csv）
- **IMP-002**: 优化用户体验，添加进度指示
- **脚本过滤优化**: 改进输出过滤逻辑，保留重要信息

### 📚 文档
- **KNOWN_ISSUES.md** - 创建已知问题汇总文档
- **WARN-001详细记录** - 完整的Java Unsafe警告问题分析
- **文档导航更新** - 更新README.md文档结构

### 🐛 已知问题
- **WARN-001**: Java 21 + Maven 3.9.11 + Guice 5.1.0 兼容性警告（已文档化，不影响功能）

### ⚡ 性能
- 导出速度基准: 2产品 + 1447设备 ≈ 3秒 (OpenJDK 21, macOS)
- 文件大小: 约292KB CSV输出

## [1.0.0] - 2026-01-05

### 🎉 首次发布
- **产品数据导出** - 支持AEP平台产品信息导出
- **设备数据导出** - 支持设备详细信息导出
- **多格式支持** - JSON和CSV格式输出
- **命令行工具** - 完整的命令行参数支持
- **环境变量配置** - 安全的认证信息管理
- **错误处理** - 完整的错误处理和日志记录

### 🛠️ 技术栈
- **Java**: OpenJDK 21 LTS (推荐)
- **构建工具**: Maven 3.9.11 + 传统javac支持
- **依赖**: AEP官方SDK + Apache HTTP Client
- **操作系统**: macOS, Linux, Windows

### 📋 基础功能
- `--export-all` - 导出所有产品和设备数据
- `--export-products` - 仅导出产品数据
- `--export-devices` - 导出指定产品的设备数据
- `--format json|csv` - 指定输出格式
- `--output-dir` - 自定义输出目录

## 版本说明

### 🏷️ 版本编号规则
- **主版本号**: 重大架构变更或不兼容更新
- **次版本号**: 新功能添加或重要改进
- **修订版本号**: Bug修复和小幅改进

### 📅 发布周期
- **主版本**: 根据重大功能需求
- **次版本**: 每月或根据功能完成度
- **修订版本**: 根据Bug修复需求

### 🎯 版本状态
- **[Unreleased]**: 开发中的功能
- **[x.y.z]**: 已发布的稳定版本
- **已知问题**: 记录在KNOWN_ISSUES.md中
