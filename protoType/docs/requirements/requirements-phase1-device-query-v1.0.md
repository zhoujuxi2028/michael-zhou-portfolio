# Phase 1 设备信息查询需求规格说明书

## 文档信息
- **版本**: v1.0
- **创建日期**: 2024-12-08
- **更新日期**: 2024-12-08
- **负责人**: Claude Code
- **状态**: 草稿
- **阶段**: Phase 1 - 原型验证阶段

## 概述

Phase 1阶段专注于设备信息查询功能的实现，作为整个云监控平台的基础模块。本阶段不涉及设备控制、告警处理、工作流等复杂功能，仅实现设备信息的查询、展示和基础管理功能。

### 项目目标
1. 验证设备信息管理的技术可行性
2. 建立基础的数据模型和API架构
3. 实现简洁直观的设备信息查询界面
4. 为后续阶段的功能扩展打下基础

### 范围限定
**包含功能:**
- 设备基础信息查询
- 设备列表展示和筛选
- 设备详情查看
- 基础的用户认证

**不包含功能:**
- 设备实时状态监控
- 告警管理
- 设备控制操作
- 工作流管理
- 地图功能
- 移动端应用

## 业务需求分析

### 用户角色定义

**UR-001: 设备管理员**
- **角色描述**: 负责设备信息管理的技术人员
- **主要职责**:
  - 查看设备基础信息
  - 检索特定设备
  - 维护设备档案数据
- **使用场景**: 日常设备信息查询和核实

**UR-002: 运维人员**
- **角色描述**: 负责设备运维的现场人员
- **主要职责**:
  - 快速查找设备信息
  - 验证设备基本参数
  - 获取设备位置信息
- **使用场景**: 现场作业前的设备信息确认

**UR-003: 系统管理员**
- **角色描述**: 负责系统管理的技术人员
- **主要职责**:
  - 管理用户权限
  - 维护设备分类和属性
  - 系统配置管理
- **使用场景**: 系统维护和数据管理

### 业务流程分析

**BF-001: 设备信息查询流程**
1. 用户登录系统
2. 进入设备管理页面
3. 使用筛选条件查询设备
4. 查看设备列表结果
5. 点击查看设备详细信息
6. 必要时导出查询结果

**BF-002: 设备信息维护流程**
1. 系统管理员登录
2. 进入设备管理后台
3. 查找需要修改的设备
4. 编辑设备基础信息
5. 保存并验证更新结果

## 功能需求规格

### 1. 设备信息查询功能

#### FR-P1-001: 设备列表查询
**需求描述**: 支持设备信息的列表查询和展示

**功能详细说明**:
- **查询条件支持**:
  - 设备名称（支持模糊查询）
  - 设备类型（下拉选择）
  - 设备状态（在线/离线/维修中等）
  - 所属区域（层级选择）
  - 安装日期范围
  - 设备编号（精确匹配）

- **查询结果展示**:
  - 分页展示，默认每页20条记录
  - 支持列排序（按名称、类型、安装日期等）
  - 列表字段包含：设备编号、设备名称、设备类型、所属区域、安装日期、当前状态
  - 支持列表字段的自定义显示/隐藏

- **交互功能**:
  - 快速筛选按钮（常用查询条件）
  - 高级查询展开/收起
  - 查询条件重置
  - 查询历史记录（最近5次）

**验收标准**:
- 查询响应时间 < 2秒
- 支持10000+设备数据查询
- 查询结果准确性100%
- 分页功能正常工作

#### FR-P1-002: 设备详情查看
**需求描述**: 提供设备的详细信息查看功能

**功能详细说明**:
- **基础信息展示**:
  - 设备标识：设备编号、设备名称、设备类型、设备型号
  - 位置信息：所属区域、详细地址、地理坐标（经纬度）
  - 技术参数：硬件配置、软件版本、技术规格
  - 管理信息：负责人、联系方式、维护周期

- **安装信息**:
  - 安装日期、安装人员
  - 安装位置描述
  - 安装验收记录
  - 配套设施信息

- **维护记录**:
  - 历史维护记录列表
  - 维护时间、维护内容、维护人员
  - 维护前后状态对比
  - 相关文档附件

- **展示方式**:
  - 分标签页展示不同信息类别
  - 支持信息的展开/折叠
  - 关键信息高亮显示
  - 支持信息的导出（PDF/Excel）

**验收标准**:
- 详情页加载时间 < 1秒
- 信息显示完整准确
- 支持所有浏览器正常显示
- 打印和导出功能正常

#### FR-P1-003: 设备统计概览
**需求描述**: 提供设备信息的统计概览功能

**功能详细说明**:
- **数量统计**:
  - 设备总数统计
  - 按类型分组统计
  - 按状态分组统计
  - 按区域分组统计

- **分布统计**:
  - 设备类型占比饼图
  - 设备区域分布柱状图
  - 设备安装时间趋势图
  - 设备状态分布

- **展示形式**:
  - 仪表板形式展示
  - 图表可交互（点击查看详细）
  - 支持时间范围筛选
  - 支持图表导出

**验收标准**:
- 统计数据实时更新
- 图表渲染流畅
- 数据准确性100%
- 支持数据钻取查看

## 技术需求规格

### 技术架构

**TR-P1-001: 后端技术栈**
- Spring Boot 2.3.5+
- MyBatis Plus 3.4.3+
- MySQL 8.0
- Redis（缓存和会话）
- JWT（认证令牌）

**TR-P1-002: 前端技术栈**
- Vue.js 3.x
- ElementUI Plus
- Vue Router
- Axios（HTTP客户端）
- ECharts（图表组件）

**TR-P1-003: 数据库设计**
核心表结构：
```sql
-- 设备信息主表
t_device (
  device_id,          -- 设备ID (主键)
  device_code,        -- 设备编号 (唯一)
  device_name,        -- 设备名称
  device_type_id,     -- 设备类型ID (外键)
  device_model,       -- 设备型号
  install_location,   -- 安装位置
  longitude,          -- 经度
  latitude,           -- 纬度
  install_date,       -- 安装日期
  responsible_person, -- 负责人
  contact_phone,      -- 联系电话
  status,             -- 设备状态
  description,        -- 设备描述
  created_time,       -- 创建时间
  updated_time        -- 更新时间
);

-- 设备类型表
t_device_type (
  type_id,           -- 类型ID (主键)
  type_name,         -- 类型名称
  parent_type_id,    -- 父类型ID
  type_description,  -- 类型描述
  sort_order,        -- 排序
  is_active         -- 是否启用
);

-- 用户表
t_user (
  user_id,          -- 用户ID (主键)
  username,         -- 用户名
  password,         -- 密码(加密)
  real_name,        -- 真实姓名
  email,           -- 邮箱
  phone,           -- 电话
  role,            -- 角色
  status,          -- 状态
  last_login_time, -- 最后登录时间
  created_time     -- 创建时间
);
```

### API设计规范

**TR-P1-004: RESTful API设计**
```
GET    /api/devices              # 获取设备列表
GET    /api/devices/{id}         # 获取设备详情
PUT    /api/devices/{id}         # 更新设备信息
GET    /api/devices/statistics   # 获取设备统计信息
GET    /api/device-types         # 获取设备类型列表
POST   /auth/login              # 用户登录
POST   /auth/logout             # 用户登出
GET    /auth/profile            # 获取用户信息
```

**TR-P1-005: 响应数据格式**

```json
  "success": true,
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": "2024-12-08T10:00:00Z"
}
```

## 风险评估

### 技术风险
**R-P1-001: 数据库性能风险**
- **风险描述**: 大量设备数据查询可能导致性能问题
- **缓解措施**: 数据库索引优化、查询分页限制、缓存机制

**R-P1-002: 前端兼容性风险**
- **风险描述**: 不同浏览器兼容性问题
- **缓解措施**: 充分测试、渐进增强、Polyfill支持

### 业务风险
**R-P1-003: 需求理解偏差风险**
- **风险描述**: 对设备信息需求理解不准确
- **缓解措施**: 充分沟通、原型验证、迭代优化

### 时间风险
**R-P1-004: 开发周期延期风险**
- **风险描述**: 功能开发可能超出预期时间
- **缓解措施**: 合理安排优先级、并行开发、风险预留
