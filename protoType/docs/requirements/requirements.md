# 云监控平台原型项目需求概要

## 项目目标
为众成科技重新搭建现代化的云监控系统，整合现有多个分散的监控系统，提升系统现代化程度和用户体验。

## Phase 1: 设备信息查询阶段 (8周) 🎯 **当前阶段**

### 核心功能范围
专注于设备信息的查询、展示和基础管理功能：

**✅ 包含功能**:
- **设备查询**: 设备列表查询、高级筛选、分页展示
- **设备详情**: 详细信息查看、技术参数展示、维护记录
- **统计概览**: 设备统计图表、分布分析、数量统计
- **信息管理**: 设备信息编辑、分类管理、基础维护
- **用户认证**: 登录认证、权限控制、角色管理

**❌ 不包含功能** (后续阶段):
- 设备实时状态监控
- 告警管理和处置
- GIS地图功能
- 工作流管理
- 移动端应用

### 技术架构
- **后端**: Spring Boot 2.3.5+ + MyBatis Plus + MySQL 8.0
- **前端**: Vue.js 3.x + ElementUI Plus + ECharts
- **认证**: JWT Token + Redis会话
- **基础架构**: 单体应用架构，为微服务演进做准备

### 实施计划
- **Week 1**: 基础框架搭建 - 项目初始化、数据库设计、认证功能
- **Week 2-3**: 设备查询功能 - 列表查询、筛选、分页功能
- **Week 4-5**: 设备详情功能 - 详情查看、信息展示、导出功能
- **Week 6-7**: 统计管理功能 - 统计图表、信息编辑、分类管理
- **Week 8**: 测试部署验收 - 功能测试、性能优化、用户验收

### 性能目标
- 查询响应时间: ≤ 2秒
- 页面加载时间: ≤ 2秒
- 支持设备数量: ≥ 10,000台
- 并发用户数: ≥ 100人

### 验收标准
- [ ] 设备列表查询功能完整可用
- [ ] 设备详情查看功能正常
- [ ] 设备统计功能准确
- [ ] 设备信息编辑功能稳定
- [ ] 用户认证和权限控制正确
- [ ] 性能指标达到要求

## 具体功能需求

### REQ-001: 电信平台设备信息查询接口

**需求描述**: 根据设备ID从电信平台获取设备的详细信息和状态数据

**功能详细说明**:
- **输入参数**: 设备ID (Device ID)
- **数据来源**: 中国电信物联网平台
- **输出结果**: 设备详细信息和实时状态

**接口规范**:
```json
{
  "deviceId": "00000bf19369481086fa22193807418d",
  "lbsId": "866094052534399",
  "cuStatus": "3",      // CU状态: 0-在线,1-告警,2-无,3-掉线
  "hubStatus": "3",     // HUB状态: 0-在线,1-告警,2-无,3-掉线
  "ru1Status": "3",     // RU1状态: 0-在线,1-告警,2-无,3-掉线
  "ru2Status": "3",     // RU2状态
  "ru3Status": "3",     // RU3状态
  "ru4Status": "3",     // RU4状态
  "ru5Status": "3",     // RU5状态 (扩展)
  "ru6Status": "3",     // RU6状态 (扩展)
  "ru7Status": "3",     // RU7状态 (扩展)
  "infoDateTime": "2023-10-17 11:56:16",  // 信息时间点
  "latitude": 0.0,      // 纬度
  "longitude": 0.0      // 经度
}
```

**验证设备信息**:
- **测试设备ID**: `00000bf19369481086fa22193807418d`
- **设备编号**: `866094052534399`
- **数据来源**: `/Users/michael_zhou/Documents/ZCT/151服务器backup数据/sql/t_deviceinfo.sql`
- **状态**: 该设备当前所有组件状态均为"3"(掉线状态)

**技术要求**:
- 支持设备ID的格式验证 (32位UUID格式)
- 支持批量查询 (一次最多100台设备)
- 查询超时时间: 10秒
- 支持缓存机制，减少重复查询
- 异常情况的错误处理和重试机制

**验收标准**:
- [ ] 单个设备查询功能正常
- [ ] 返回数据格式符合规范
- [ ] 查询超时和异常处理正确
- [ ] 批量查询功能稳定
- [ ] 性能满足要求 (单次查询 < 3秒)

**优先级**: 高
**依赖**: 电信平台API接入权限
**风险**: 电信平台API的稳定性和响应速度
