# Phase 3 代码示例

Phase 3 示例用于练习高阶提示工程，重点训练 Copilot 在上下文管理、任务拆解和审查反馈中的表现。

## 示例列表

| 示例 | 对应模块 | 说明 |
| --- | --- | --- |
| [m7-context-demo](./m7-context-demo/) | M7 | 使用学习中心本身练习上下文地图、范围收敛、多文件计划和 diff 审查。 |

## 推荐使用方式

1. 先阅读 M7 主模块，理解练习目标
2. 再打开示例目录，按练习顺序执行 prompt
3. 用自己的输出对照成功标准，检查遗漏点
4. 最后把得到的结论回写到学习中心相关文档中
