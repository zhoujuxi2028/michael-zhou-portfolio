### 2. 实战场景验证

**场景 1 — 整理个人 Prompt 精华库**

- 把 M1-M14 积累的提示记录（摘要形式）传给 Copilot，提炼共同规律，生成各场景"最佳模板"
- 关键发现：有效提示的共同规律——指定格式要求（如"Google 风格"）+ 明确数量和类型（如"3 happy path + 3 edge case"）+ 提供示例；仅一句话的提示质量普遍差
- 效果：从分散的历史记录中提炼出 5 个场景的标准模板，覆盖测试/文档/代码审查/调试/Git 工作流

**场景 2 — 编写个人学习总结框架**

- 面向 QA 工程师同行，生成含五个章节和每章引导问题的写作框架
- 关键发现：每条洞察要用"原来的工作方式 vs 用了 Copilot 之后 + 效率数据"的结构记录，才有参考价值；只记录"是什么"而不写"为什么和数据"的总结参考价值有限
- 效果：写作框架覆盖执行摘要、有效场景、超出预期发现、局限性客观分析、给同行的建议五部分，可直接填写并对外分享

**场景 3 — 制定下一阶段改进计划**

- 提供当前能力评估（⭐1-5 分），生成针对薄弱项的 3 个月月度目标和可量化验证方式
- 关键发现：目标必须细化到"每周行动项"才有执行性；月度目标过多会导致完成率极低（< 30%）；每个目标配一个"验证方式"是计划可执行的关键
- 效果：3 个月计划拆解为 12 周行动项，每周目标明确可验证，避免计划宏大但落地差的问题
