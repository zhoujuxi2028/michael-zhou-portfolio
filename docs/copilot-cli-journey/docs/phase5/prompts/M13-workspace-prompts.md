# M13 Copilot Workspace Prompt 模板库

本模板库用于在 Copilot Workspace 工作前后与 CLI 配合使用，提升 Workspace 方案质量。

## 快速选择表

| 场景 | 推荐模板 | 目标 |
|------|---------|------|
| Workspace 启动前快速分析 | T1 前置 CLI 分析 | 缩小 Workspace 分析范围 |
| 补充 Workspace 遗漏的边界测试 | T2 边界测试补充 | 覆盖 Workspace 未识别的测试场景 |
| 审查 Workspace 生成的 PR | T3 PR 安全审查 | 检查安全性和逻辑正确性 |

---

## T1：Workspace 启动前快速分析

适用于：在用 Workspace 处理 Issue 前，先用 CLI 快速缩小问题范围。

```text
请分析以下文件中与 {Issue 描述的问题} 相关的逻辑：

{粘贴相关文件内容}

重点关注：
1. 可能的根因位置（文件名 + 行号范围）
2. 涉及的其他文件（如有依赖关系）
3. 最可能的修复方向（1-2 句话）

不要修改代码，只做分析。
```

---

## T2：Workspace PR 边界测试补充

适用于：Workspace 生成 PR 后，用 CLI 补充主路径以外的边界测试。

```text
以上是 PR 的 diff，请列出：
1. 所有新增的公开函数/方法
2. 对于每个函数，列出 3 个最重要的缺失测试场景（含输入/预期输出）
   重点关注：边界值、空值/null、异常路径
不需要生成代码，只列出场景描述。
```

**使用方式**：
```bash
git diff main...HEAD -- src/ | gh copilot suggest "$(cat 上面的模板)"
```

---

## T3：Workspace PR 安全审查

适用于：对 Workspace 生成的代码进行安全性快速检查。

```text
请对以上 PR 修改的代码进行安全审查，重点检查：
1. 是否有未验证的用户输入（SQL 注入/XSS 风险）
2. 是否有硬编码的敏感信息（token/密码/密钥）
3. 是否有不安全的权限处理（越权访问风险）
4. 是否有不当的错误信息暴露
对每个发现的风险给出具体位置和修复建议。
```
