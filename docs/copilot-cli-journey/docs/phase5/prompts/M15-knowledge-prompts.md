# M15 知识库总结 Prompt 模板库

本模板库用于整理个人 Prompt 精华、撰写学习总结，以及制定改进计划。

## 快速选择表

| 场景 | 推荐模板 | 目标 |
|------|---------|------|
| 提炼 Prompt 规律 | T1 Prompt 规律提炼 | 从历史提示中提取共同模式 |
| 撰写学习总结框架 | T2 总结写作框架 | 生成带引导问题的写作结构 |
| 制定改进计划 | T3 能力改进规划 | 从评估到月度目标分解 |

---

## T1：Prompt 规律提炼

适用于：整理过去一段时间的提示记录，提炼最有效的模式。

```text
我整理了以下在 {时间段} 中使用 Copilot CLI 的提示记录（摘要）：

{场景名称}：
- {提示描述}（效果：好/差）
- {提示描述}（效果：好/差）
...

请帮我：
1. 找出效果好的提示的共同规律（具体指出是上下文/格式/约束/示例哪个维度）
2. 找出效果差的提示的共同问题
3. 为 {最常用的 2-3 个场景} 各生成一个"最佳模板"
4. 指出我目前可能遗漏的高价值场景
```

---

## T2：学习总结写作框架

适用于：把 Copilot 学习经历整理为可分享的技术文章或 Portfolio。

```text
请帮我生成一个"GitHub Copilot CLI 学习总结"的写作框架：

面向读者：{目标读者（如：QA 工程师，2 年以上测试经验）}
学习背景：{学习时长和主要内容}

框架需包含以下部分，每部分提供 3-5 个引导问题帮我填写：
1. 执行摘要（3-5 句话概括最重要的发现）
2. 最有效的 {N} 个使用场景（附效率数据）
3. 超出预期的发现
4. 局限性和不适用场景
5. 给 {目标读者} 的 {N} 条建议
```

---

## T3：能力改进规划

适用于：基于当前能力自评，生成可执行的改进计划。

```text
请根据以下我当前的 Copilot CLI 使用能力评估，制定一个 {时长} 的改进计划：

能力评估（1-5 星）：
- {能力维度}: ⭐⭐⭐（当前水平描述）
- {能力维度}: ⭐⭐（当前水平描述）
...

改进目标：
{列出 2-3 个具体目标}

计划要求：
- 按月分解，每月 1-2 个聚焦目标
- 每个目标配一个可量化的验证方式
- 每月目标进一步拆解为每周行动项
- 避免目标过多（每月不超过 2 个）
```
