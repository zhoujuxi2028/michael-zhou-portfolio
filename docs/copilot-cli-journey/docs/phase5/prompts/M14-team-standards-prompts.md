# M14 团队标准化 Prompt 模板库

本模板库用于生成团队 Copilot 使用规范、Prompt 模板，以及 Onboarding 计划。

## 快速选择表

| 场景 | 推荐模板 | 目标 |
|------|---------|------|
| 起草团队使用规范 | T1 使用规范生成 | 含安全红线和质量要求 |
| 设计参数化 Prompt 模板 | T2 模板标准化 | 含占位符、示例、局限说明 |
| 制定 Onboarding 计划 | T3 Onboarding 设计 | 5 天实践任务含验收标准 |

---

## T1：团队 Copilot 使用规范生成

```text
请为以下团队生成 GitHub Copilot CLI 使用规范文档：

团队背景：
- 规模：{人数} 人 {角色} 团队
- 技术栈：{语言和框架}
- CI/CD：{工具}
- 代码规范：{风格指南}

规范文档需包含：
1. 适用场景（明确什么时候用 Copilot，什么时候不用）
2. 安全红线（不允许发送给 Copilot 的信息类型）
3. 质量检查（生成代码必须通过的验证步骤）
4. 主要场景的标准 Prompt 模板（{场景列表}）
5. 反模式（明确禁止的使用方式，附说明原因）

每条规范附一个 good/bad 对比示例。用 Markdown 格式输出。
```

---

## T2：Prompt 模板标准化

适用于：把一个有效的提示规范化为团队可复用的标准模板。

```text
以下是一个效果不错的 Copilot 提示：
{原始提示}

请将其标准化为团队模板格式：
1. 用 {占位符} 标注所有可变部分
2. 添加"适用情况"说明（什么场景下使用）
3. 添加"已知局限"说明（什么情况下效果不好）
4. 提供一个"好的使用示例"（填入真实值）

输出 Markdown 格式。
```

## T3：Onboarding 计划设计

```text
为以下新成员设计一个 5 天 GitHub Copilot CLI Onboarding 计划：

成员背景：
- 测试经验：{年数}
- 编程水平：{语言和熟练度}
- 已有工具经验：{工具列表}

团队工具链：{工具列表}

学习目标：{具体能力目标}

计划要求：
- 每天 1-2 个具体实践任务
- 每个任务有可量化的验收标准
- 第 5 天完成一个综合小项目作为能力验收
- 每天结束时有一个"能独立完成的操作"作为进度指标
```
