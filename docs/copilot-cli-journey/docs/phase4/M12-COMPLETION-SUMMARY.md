### 2. 实战场景验证

**场景 1 — k6 负载测试脚本生成**

- 提供 API 端点、测试场景（100 并发/5 分钟）和 threshold 目标，生成含随机数据和完整注释的 k6 脚本
- 关键发现：需在提示中要求"每次请求使用随机测试数据"，否则数据库缓存会导致结果失真；TOKEN 需通过 `__ENV.API_TOKEN` 读取
- 效果：完整 k6 脚本（stages + thresholds + 随机化 + 错误率追踪）5 分钟内生成，直接可运行

**场景 2 — 性能测试结果分析**

- 用 `k6 run --out json` 输出结果，通过 jq 提取 P95/P99/RPS/错误率后传给 Copilot 分析
- 关键发现：直接传完整 JSON 输出过长；先用 jq 提取关键指标再分析效果显著更好
- 效果：30 秒内获得"是否达标 + 瓶颈定位 + 3 个优化建议（按可能性排序）"的结构化分析

**场景 3 — Soak Test 稳定性测试脚本**

- 生成 24 小时、30 并发用户的 Soak Test 脚本，含每小时性能退化检测和错误率超阈中止逻辑
- 关键发现：需说明"为什么用低并发"让 Copilot 加入注释解释（Soak Test 目的是检测内存泄漏和性能退化，不是压测极限）
- 效果：脚本含完整告警逻辑（P95 > 1000ms 警告、错误率 > 5% 中止），可直接用于上线前验证
