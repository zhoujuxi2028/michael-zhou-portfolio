## 核心学习成果

完成 M7 后，学习者应能在 Copilot CLI 中稳定完成以下工作：

1. **先理解再执行**：在修改前要求 Copilot 建立上下文地图，避免直接生成无边界方案。
2. **明确改动边界**：用“必须修改 / 可能修改 / 不应修改”约束任务范围。
3. **拆成可验证步骤**：把多文件任务拆成 3-5 个步骤，并为每一步定义输入、输出和验证方式。
4. **用 diff 审查范围**：优先检查是否满足目标、是否有无关改动、链接和导航是否同步。
5. **维护长会话质量**：通过阶段性摘要和 `/compact` 保留关键约束，减少上下文漂移。
