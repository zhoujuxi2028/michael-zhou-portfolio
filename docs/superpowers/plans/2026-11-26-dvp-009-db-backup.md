# REQ-DVP-009 DB 备份自动化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** k3d 上的 PostgreSQL 16 每日自动 `pg_dump` 到 LocalStack S3（附 manifest），脚本执行保留策略，每周恢复演练按 manifest 校验，结果推送 Pushgateway 并由 `BackupFailed` / `BackupStale` 告警覆盖。

**Architecture:** Terraform 新增备份 bucket（lifecycle 仅真实 AWS）与 2 个 Secrets Manager secret；ESO 在新 namespace `data-pipeline` 同步 DB / S3 凭据。Kustomize（`data-pipeline/kustomization.yaml`）部署 Postgres StatefulSet + 两个 CronJob：`db-backup`（`dump` postgres 容器 + `upload` aws-cli 容器，经 emptyDir 中的 rc 文件交接）与 `db-restore-drill`（native sidecar 临时 Postgres + `fetch` + `verify`）。备份 / 保留 / 恢复逻辑全部在 `data-pipeline/scripts/*.sh`，同一份文件既由 configMapGenerator 挂进 Pod，也由 fake CLI 单元测试覆盖。告警规则用 `promtool test rules` 离线验证。

**Tech Stack:** PostgreSQL 16（`postgres:16-alpine`）、`amazon/aws-cli:2.42.4`、Kustomize（kubectl 内置）、External Secrets Operator 2.15.0（`external-secrets.io/v1`）、Terraform（aws ~6.46；本机 1.5.7 / CI ~1.7，`terraform test` 用 `hashicorp/terraform:1.7` 容器）、LocalStack 3.8、Pushgateway v1.11.5、promtool（`prom/prometheus:v3.16.0`）、bash + busybox/GNU/BSD 兼容

## 开放项决定（spec §5 / §7）

| 开放项 | 决定 | 理由 | 代价 / 回退 |
|--------|------|------|-------------|
| K8s 打包：`data-pipeline/k8s/` vs 独立 Helm chart | **Kustomize**：`data-pipeline/kustomization.yaml` + `data-pipeline/k8s/*.yaml` | ① `configMapGenerator` 直接挂载 `data-pipeline/scripts/*.sh`，单测与 Pod 用同一份文件（Helm `.Files.Get` 要求文件在 chart 内 → 复制或软链）；② `kubectl apply -k` 内置，无 Helm 4.1/3.14 漂移；③ 单环境、无模板需求；④ 与 `monitoring/eso/` 纯清单一致 | 无 release / rollback / values；环境差异（endpoint、bucket）为 kustomization literal，真实 AWS 需加 overlay。kustomization 放在 `data-pipeline/` 根，因 generator 只能引用根目录及子目录文件 |
| S3 客户端：`amazon/aws-cli` vs boto3 小镜像 | **`amazon/aws-cli:2.42.4`**（官方，固定版本） | 符合 D3「复用官方镜像、不维护新镜像」；真实 AWS 原样可用（IRSA、分页、multipart）；单测用 fake `aws` | 一次性拉取 ~143 MB，`k3d image import` 后集群内不再拉取。否决 boto3：需构建 / 扫描 / 推 registry 新镜像，python 基础镜像未缓存。否决 `curl --aws-sigv4`（零新镜像）：需手写 XML 列表解析与分页，真实 AWS sigv4 细节风险。Docker Hub 慢时回退 `public.ecr.aws/aws-cli/aws-cli:2.42.4` 并 `docker tag` |
| Pod 拓扑 | 两个主容器 + `/work/*.rc` 文件交接（不用 initContainer） | initContainer 中 `pg_dump` 失败 → 主容器不运行 → 不推 `status=0`，`BackupFailed` 永不触发 | 需 `wait_rc` 超时（600s）+ `activeDeadlineSeconds: 900` |
| 指标推送 | postgres 容器内 busybox `wget --post-file`（Task 1 验证） | aws-cli 镜像不保证有 curl；postgres 镜像已有 wget | — |
| 临时实例认证 | `POSTGRES_HOST_AUTH_METHOD=trust` + `listen_addresses=127.0.0.1` | Pod 内回环、Job 结束即销毁，无需第三份凭据 | 仅限 drill sidecar |
| Terraform lifecycle | 无论 Task 2 结果均保持 `count = var.use_localstack ? 0 : 1` | D2：LocalStack 不执行过期，开启无功能收益；结果记录到 DB-BACKUP.md | 若 Task 2 PASS，另开 issue 评估 #47 artifacts bucket 的跳过 |
| 告警验证 | `promtool test rules`（离线 + CI）+ 轻量 Pushgateway 看指标 | 完整监控栈未安装，8 GiB 限制 | Grafana / Alertmanager e2e 为可选步骤 |

```bash
TABLE_COUNTS_SQL="SELECT n.nspname || '.' || c.relname,

WHERE c.relkind IN ('r', 'p')

wait_rc() {  # wait_rc <file> <timeout-seconds> → prints rc; returns 1 on timeout
  local waited=0
  while [ ! -f "$1" ]; do
    if [ "$waited" -ge "$2" ]; then
      log "timeout after ${2}s waiting for $1"
      return 1
    fi
    sleep 1
    waited=$((waited + 1))
  done

  sed -n "s#^${BACKUP_PREFIX}\([0-9]\{8\}T[0-9]\{6\}Z\)/manifest\.json\$#\1#p" "$1" | LC_ALL=C sort -u
}

# --- Postgres + manifest ----------------------------------------------------------------

db_table_counts() {  # db_table_counts <out-file> (libpq env: PGHOST PGUSER PGDATABASE ...)
  psql -XAtq -v ON_ERROR_STOP=1 -c "$TABLE_COUNTS_SQL" > "$1.raw"
  LC_ALL=C sort "$1.raw" > "$1"
  rm -f "$1.raw"
}

# manifest_write <dump> <counts-file> <ts> <database> <out> — one key per line (parsed by sed below)
manifest_write() {
  local dump=$1 counts=$2 ts=$3 db=$4 out=$5 sha size name count first=1
  sha=$(sha256sum "$dump" | awk '{print $1}')
  size=$(wc -c < "$dump" | tr -d ' ')
  {
    printf '{\n'
    printf '  "version": 1,\n'
    printf '  "timestamp": "%s",\n' "$ts"
    printf '  "database": "%s",\n' "$db"
    printf '  "dump_file": "%s",\n' "$(basename "$dump")"
    printf '  "dump_sha256": "%s",\n' "$sha"
    printf '  "dump_size_bytes": %s,\n' "$size"
    printf '  "tables": {'
    while IFS='|' read -r name count; do
      if [ -z "$name" ]; then continue; fi
      case "$name" in *'"'* | *'\'*) die "unsupported table name: $name" ;; esac
      [[ "$count" =~ ^[0-9]+$ ]] || die "invalid row count for $name: '$count'"
      if [ "$first" = 1 ]; then printf '\n'; first=0; else printf ',\n'; fi
      printf '    "%s": %s' "$name" "$count"
    done < "$counts"
    printf '\n  }\n}\n'
  } > "$out"
}

manifest_sha() { sed -n 's/^  "dump_sha256": "\([0-9a-f]\{64\}\)",$/\1/p' "$1"; }

manifest_tables() {  # → sorted "<schema>.<table>|<count>"
  sed -n '/^  "tables": {/,/^  }$/p' "$1" \
    | sed -n 's/^    "\([^"]*\)": \([0-9]*\),\{0,1\}$/\1|\2/p' | LC_ALL=C sort
}

verify_sha() {  # verify_sha <manifest> <dump>
  local want got
  want=$(manifest_sha "$1")
  [ -n "$want" ] || die "manifest has no dump_sha256: $1"
  got=$(sha256sum "$2" | awk '{print $1}')
  [ "$want" = "$got" ] || die "sha256 mismatch: manifest=$want actual=$got"
}

compare_counts() {  # compare_counts <manifest> <actual-counts-file>
  local want got
  want=$(manifest_tables "$1")
  got=$(LC_ALL=C sort "$2")
  [ -n "$want" ] || die "manifest lists no tables"
  if [ "$want" != "$got" ]; then
    log "expected (manifest): $(printf '%s' "$want" | tr '\n' ' ')"
    log "actual   (restored): $(printf '%s' "$got" | tr '\n' ' ')"
    die "row count mismatch"
  fi
}

# --- Pushgateway ------------------------------------------------------------------------

# push_metrics <job> <instance> <file> — POST: replaces only the metric names in <file>,
# so backup_last_success_timestamp survives a failed run. Empty PUSHGATEWAY_URL = disabled.
push_metrics() {
  local url
  if [ -z "${PUSHGATEWAY_URL:-}" ]; then
    log "PUSHGATEWAY_URL empty — metrics push disabled"
    cat "$3" >&2
    return 0
  fi
  url="${PUSHGATEWAY_URL%/}/metrics/job/$1/instance/$2"
  if ! wget -q -O /dev/null -T 10 --header='Content-Type: text/plain; version=0.0.4' \
       --post-file="$3" "$url"; then
    log "ERROR: metrics push failed: $url"
    return 1
  fi
  log "metrics pushed: $url"
}
```

```bash
#!/usr/bin/env bash
# retention.sh — delete backup prefixes older than RETENTION_DAYS (REQ-DVP-009 FR-02 / D2)
#
# LocalStack 3.8 stores lifecycle rules but never expires objects (spike 2026-11-26), so
# retention is enforced here; on real AWS the Terraform lifecycle rule (+7 days) is a safety net.
#   - only ${BACKUP_PREFIX}<YYYYMMDDTHHMMSSZ>/ prefixes are considered (e.g. manual/ is untouched)
#   - timestamp < cutoff (now - RETENTION_DAYS days) → the whole prefix is deleted
#   - the newest KEEP_MIN complete backups (with manifest.json) are never deleted
#
# Env: S3_BUCKET (required) BACKUP_PREFIX (backups/) RETENTION_DAYS (required, >=1)
#      KEEP_MIN (1) DRY_RUN=1 (print only) NOW (epoch, tests only)
# Exit: 0 ok | 1 aws / config error | 2 invalid RETENTION_DAYS / KEEP_MIN
set -euo pipefail

if ! [[ "$RETENTION_DAYS" =~ ^[1-9][0-9]*$ ]]; then
  log "ERROR: RETENTION_DAYS must be a positive integer (got '$RETENTION_DAYS')"
  exit 2
fi
if ! [[ "$KEEP_MIN" =~ ^[0-9]+$ ]]; then
  log "ERROR: KEEP_MIN must be a non-negative integer (got '$KEEP_MIN')"
  exit 2
fi

now="${NOW:-$(date +%s)}"

tmp=$(mktemp -d)
trap 'rm -rf "$tmp"' EXIT

list_keys "$tmp/keys"
backup_ts_all "$tmp/keys" > "$tmp/all"
backup_ts_complete "$tmp/keys" | tail -n "$KEEP_MIN" > "$tmp/protected"

kept=0
deleted=0
while read -r ts; do
  if [[ "$ts" < "$cutoff" ]] && ! grep -qx "$ts" "$tmp/protected"; then
    log "DELETE ${BACKUP_PREFIX}${ts}/ (older than $cutoff)"
    if [ "${DRY_RUN:-0}" != 1 ]; then
      aws s3 rm "s3://$S3_BUCKET/${BACKUP_PREFIX}${ts}/" --recursive --only-show-errors
    fi
    deleted=$((deleted + 1))
  else
    kept=$((kept + 1))
  fi
done < "$tmp/all"
```

```bash
#!/usr/bin/env bash
# s3-backup.sh — S3 side of DB backup / restore drill (REQ-DVP-009); runs in amazon/aws-cli
#
#   upload        wait dump.rc=0 → upload db.dump, then manifest.json → retention.sh; EXIT writes upload.rc
#   fetch-latest  newest complete backup (has manifest.json) → $WORK_DIR/restore/; EXIT writes fetch.rc
#
# Env: S3_BUCKET (required) BACKUP_PREFIX (backups/) WORK_DIR (/work) RC_WAIT_TIMEOUT (600)
#      aws CLI: AWS_ENDPOINT_URL AWS_REGION AWS_ACCESS_KEY_ID AWS_SECRET_ACCESS_KEY AWS_CONFIG_FILE
set -euo pipefail
DIR="$(cd "$(dirname "$0")" && pwd)"
# shellcheck source=lib.sh
. "$DIR/lib.sh"

: "${S3_BUCKET:?S3_BUCKET is required}"
BACKUP_PREFIX="${BACKUP_PREFIX:-backups/}"
WORK_DIR="${WORK_DIR:-/work}"
RC_WAIT_TIMEOUT="${RC_WAIT_TIMEOUT:-600}"
check_prefix "$BACKUP_PREFIX"
trap 'exit 143' TERM

upload() {
  local dump_rc ts dest
  trap 'write_rc "$WORK_DIR/upload.rc" "$?"' EXIT
  dump_rc=$(wait_rc "$WORK_DIR/dump.rc" "$RC_WAIT_TIMEOUT")
  if [ "$dump_rc" != 0 ]; then
    log "dump failed (rc=$dump_rc) — upload skipped; backup.sh reports the failure"
    exit 0
  fi
  ts=$(cat "$WORK_DIR/ts")
  is_ts "$ts" || die "invalid backup timestamp: '$ts'"
  dest="s3://$S3_BUCKET/${BACKUP_PREFIX}${ts}"
  # manifest.json last: a prefix with manifest.json is a complete backup
  aws s3 cp "$WORK_DIR/out/db.dump" "$dest/db.dump" --only-show-errors
  aws s3 cp "$WORK_DIR/out/manifest.json" "$dest/manifest.json" --only-show-errors
  log "uploaded $dest/"
  bash "$DIR/retention.sh"
}

fetch_latest() {
  local keys ts src dst="$WORK_DIR/restore"
  trap 'write_rc "$WORK_DIR/fetch.rc" "$?"' EXIT
  keys=$(mktemp)
  list_keys "$keys"
  ts=$(backup_ts_complete "$keys" | tail -n 1)
  rm -f "$keys"
  [ -n "$ts" ] || die "no complete backup under s3://$S3_BUCKET/$BACKUP_PREFIX"
  src="s3://$S3_BUCKET/${BACKUP_PREFIX}${ts}"
  mkdir -p "$dst"
  aws s3 cp "$src/manifest.json" "$dst/manifest.json" --only-show-errors
  aws s3 cp "$src/db.dump" "$dst/db.dump" --only-show-errors
  printf '%s\n' "$ts" > "$dst/ts"
  log "fetched $src/"
}

case "${1:-}" in
  upload)       upload ;;
  fetch-latest) fetch_latest ;;
  *)            echo "Usage: s3-backup.sh upload|fetch-latest" >&2; exit 2 ;;
esac
```

````markdown
# DB 备份自动化（REQ-DVP-009）

PostgreSQL 16 每日备份到 LocalStack S3，脚本执行保留策略，每周恢复演练按 manifest 校验，指标进入 Pushgateway 并由 `BackupFailed` / `BackupStale` 告警。

## 概览

```
Secrets Manager (LocalStack) ──ESO──▶ Secret pg-credentials / backup-s3-creds   (ns data-pipeline)
                                              │
CronJob db-backup (02:00 UTC)                 ▼
  dump   (postgres)  pg_dump -Fc → /work/out/db.dump + manifest.json → dump.rc
  upload (aws-cli)   s3 cp → s3://portfolio-dev-db-backups/backups/<ts>/ → retention.sh → upload.rc
  dump   (postgres)  wget POST → Pushgateway (backup_*)
                                              │
CronJob db-restore-drill (周日 04:00 UTC)      ▼
  scratch-db (sidecar)  临时 Postgres（127.0.0.1，trust，emptyDir）
  fetch  (aws-cli)      最新完整备份 → /work/restore → fetch.rc
  verify (postgres)     sha256 → pg_restore → 行数比对 → Pushgateway (restore_*)
                                              ▼
Prometheus ── PrometheusRule (BackupFailed / BackupStale) ── Alertmanager；Grafana `db-backup`
```

| 组件 | 文件 |
|------|------|
| Terraform | `terraform/backup.tf`（bucket、lifecycle 仅真实 AWS、2 secret） |
| 脚本 | `data-pipeline/scripts/`（`backup.sh`、`s3-backup.sh`、`retention.sh`、`restore-drill.sh`、`lib.sh`） |
| K8s | `data-pipeline/kustomization.yaml` + `data-pipeline/k8s/` |
| 告警 / 面板 | `monitoring/alertrules/backup-alerts.yaml`、`monitoring/dashboards/db-backup.json` |
| 测试 | `tests/test-backup-{retention,scripts,alerts}.sh`、`tests/test-db-backup-manifests.sh`、`terraform/tests/backup.tftest.hcl` |

### 指标（Pushgateway，`instance=appdb`）

|------|-----|---------|

| `backup_size_bytes`、`backup_last_success_timestamp` | `db_backup` | 仅成功 |

## 排障

| 现象 | 原因 | 处理 |
|------|------|------|
| Pod `CreateContainerConfigError` | `pg-credentials` / `backup-s3-creds` 未同步 | `kc describe externalsecret`；LocalStack 重启后重跑 terraform apply |
| `dump` 日志 `password authentication failed` | Secrets Manager 密码与库内密码不一致（首次 initdb 后改了 secret） | 恢复原密码，或在库内 `ALTER USER` 后同步 |
| `upload` 日志 `Could not connect to the endpoint URL` | `host.k3d.internal` 不可解析 | `k3d cluster stop/start portfolio-dev` |
| `upload` 日志 `NoSuchBucket` | LocalStack 重启丢失 bucket | 重跑 terraform apply |
| `metrics push failed` | Pushgateway 不存在 / 服务名不同 | 部署 `pushgateway-lite.yaml` 或改 kustomization 中 `PUSHGATEWAY_URL` |
| `timeout after 600s waiting for` | 对侧容器未启动（镜像拉取失败） | `kc describe pod`；`k3d image import` |
| `sha256 mismatch` / `row count mismatch` | 备份损坏或 manifest 与 dump 不一致 | 用更早的完整备份演练；检查备份时是否有并发写入 |

## 迁移到真实 AWS

| 本地 | 真实 AWS |
|------|---------|
| `AWS_ENDPOINT_URL` + `AWS_CONFIG_FILE`（path-style） | overlay 中删除 |
| `backup-s3-creds`（静态密钥） | IRSA：ServiceAccount 注解 role ARN，删除 secret 与 `envFrom` |
| `retention.sh` 唯一保留机制 | 仍执行；另有 lifecycle（保留期 + 7 天）+ noncurrent 7 天 |
| 无加密 | KMS SSE（`aws_kms_key.s3`）+ versioning |
| `S3_BUCKET=portfolio-dev-db-backups` | `terraform output db_backups_bucket_name` |

|----|------|
| LocalStack lifecycle | 3.8 存储规则但不执行过期；Terraform lifecycle 资源在 LocalStack 上的结果：<Task 2 结果（PASS / FAIL + 原因）> |
````
