# 最佳实践指南

**范围**: 项目级开发规范和工具  
**用途**: 指导日常开发、项目规划、代码实现、文档管理

---

## 📋 目录

### 1. [文档编写规范](./documentation-standards.md)
文档管理的原则、规范和检查清单，涵盖：
- 单一信息来源（SSOT）原则
- 避免重复维护
- 创建新文档的检查清单
- 文件命名约定
- PR 审查流程

### 2. [实现清单](./implementation-checklist.md)
项目开发的全过程检查清单，涵盖：
- 需求分析
- 设计评审
- 代码实现
- 测试验证
- 文档完成
- 交付前准备

### 3. [规划模板](./templates/plan-template.md)
项目规划和任务管理的标准模板。

---

## 🚀 快速使用

### 新项目启动
1. 查看 [文档编写规范](./documentation-standards.md) — 了解文档管理原则
2. 查看 [实现清单](./implementation-checklist.md) — 了解开发全流程
3. 使用 [规划模板](./templates/plan-template.md) — 制定项目计划
4. 按清单逐步推进

### 中途参考
- 需要文档指导？查看 [文档编写规范](./documentation-standards.md)
- 需要检查进度？查看 [实现清单](./implementation-checklist.md) 的检查项
- 需要规划分解任务？使用 [规划模板](./templates/plan-template.md)
