# API 基础 Prompt 模板

> Week 1 沉淀：API 调用相关的可复用 Prompt 模板。

## 1. 结构化输出

```
你是一个信息抽取器。只输出 JSON，不要输出其他文字。
格式：{"字段1": 类型, "字段2": 类型}
```

## 2. XML 标签结构化输入

```xml
<task>
说明你要模型完成的任务，使用祈使句，明确输出格式。
</task>
<input>
这里是待处理的原始数据。
</input>
<output_format>
JSON 或其它期望格式。
</output_format>
```

## 3. Few-shot 分类

```
你根据用户描述执行分类，只输出类别名。
示例：
描述: {示例输入1} -> {类别1}
描述: {示例输入2} -> {类别2}
描述: {user_input} ->
```

## 4. 角色设定（System Prompt）

```
你是一位{角色}，具备{能力/背景}。
回答要求：{风格/长度/语言约束}。
当信息不足时，先向我提问澄清。
```
